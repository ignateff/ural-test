# Подбор автозапчастей

Поиск искомой детали, её аналогов и складских предложений поставщика.

## Language

**Артикул**:
Номер детали у производителя. Один артикул может встречаться у нескольких производителей.
_Avoid_: уникальный идентификатор детали

**Искомая деталь**:
Деталь, заданная сочетанием артикула и выбранного производителя.
_Avoid_: товар, определённый только артикулом

**Производитель искомой детали**:
Производитель, выбранный после поиска по артикулу и определяющий исходную деталь для подбора аналогов.
_Avoid_: фильтр по производителю аналогов

**Аналог**:
Деталь, которую поставщик указывает как замену искомой детали.

**Складское предложение**:
Предложение конкретной детали на конкретном складе, содержащее цену и доступный остаток.
_Avoid_: деталь, общий остаток по всем складам

**Наличие**:
Признак складского предложения с доступным остатком больше нуля.
_Avoid_: наличие детали целиком, «есть в продаже»

**Деталь без складских предложений**:
Деталь подбора, для которой поставщик не вернул ни одного складского предложения; показывается без склада и цены и считается отсутствующей в наличии.
_Avoid_: «нет в наличии» как характеристика детали

**Подбор**:
Поиск искомой детали и её аналогов, результатом которого является набор складских предложений.
_Avoid_: поиск, результаты поиска (для обозначения подбора целиком)
