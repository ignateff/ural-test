# Подбор автозапчастей

React SPA для поиска деталей, аналогов и складских предложений Favorit Parts.
Стек: JavaScript, React 19, Redux Toolkit, Bootstrap, Vite и TanStack Virtual.

## Запуск

Требуется Node.js 22.20+ или 24.12+.

```sh
npm ci
npm run dev
```

Примеры артикулов: `01089` (ASAM или FEBI), `7160500039S`.
После паузы ввода 500 мс загружаются производители; выбор производителя запускает
поиск предложений. Запросы идут из браузера прямо к HTTPS API Favorit Parts.

По умолчанию используется публичный пример ключа из документации поставщика.
Его доступность и лимиты зависят от поставщика. Чтобы задать другой ключ,
скопируйте `.env.example` в `.env` и измените `VITE_FAVORIT_API_KEY`.
Значения `VITE_*` доступны посетителям в клиентской сборке.

## Возможности и решения

- Поиск деталей и аналогов с ценой и остатком каждого складского предложения.
- Фильтрация по наличию, складу, производителю, типу детали и диапазону цен.
- Сортировка по цене, остатку, производителю и складу.
- Сохранение поиска, фильтров и сортировки в URL для передачи ссылки.
- Адаптивная таблица: карточки на мобильных экранах, виртуализация свыше 100 строк.
- Панель фильтров с поиском и множественным выбором, теги выбранных условий.
- Загрузка, пустые результаты, повтор запроса, таймаут и отмена устаревших запросов.
- Сохранение предыдущих результатов во время обновления с временной блокировкой действий.

API нормализуется в отдельном модуле; состояние и асинхронные запросы находятся
в Redux Toolkit. Фильтрация и сортировка выполняются локально перед виртуализацией.
Детали без складских предложений сохраняются в результате без цены и склада.

Интерфейс поддерживает клавиатуру, видимый фокус, сообщения статуса для скринридера
и уменьшение анимации. Панель фильтров использует нативный `dialog`, удерживает фокус
и возвращает его к кнопке после закрытия.

Ограничения: браузерный поиск и печать видят только отрисованную часть
виртуализированной таблицы. Автоматический аудит доступности не заменяет
ручную проверку скринридером.

## Структура

```text
src/
  app/                # страница, Redux store, тема и общие стили
  parts-search/
    api/              # HTTP API и нормализация ответа
    model/            # состояние, фильтрация, сортировка и URL
    ui/               # поиск, предложения, фильтры и сообщения

test/                 # модель и интеграционные проверки React/Redux
  support/            # помощники и HTTP-заглушки
e2e/                  # браузерные проверки Playwright
```

## Проверки

```sh
npm run check                 # Prettier, Vitest и production-сборка
npm run test:a11y             # проверки доступности, включая axe
npx playwright install chromium
npm run test:browser           # браузерные сценарии
```

Vitest использует настоящие React и Redux с подменой `fetch`. Playwright проверяет
фильтры, URL, управление клавиатурой, адаптивность и виртуализацию в Chromium
на подготовленных HTTP-ответах. Он сам запускает Vite на `127.0.0.1:4173`;
порт должен быть свободен. Доступ к внешнему API для тестов не требуется.
JSDOM не рассчитывает геометрию и контраст; эти ограничения учитываются в проверках.

GitHub Actions выполняет проверки на push и pull request. При ошибках браузерных
тестов сохраняет HTML-отчёт, trace и скриншоты.

## Сборка и GitHub Pages

```sh
npm run build
npm run preview
```

Результат сборки находится в `dist/`.

1. Отправьте ветку `main` в GitHub-репозиторий.
2. В **Settings → Pages → Build and deployment → Source** выберите **GitHub Actions**.
3. Запустите workflow **Deploy to GitHub Pages** во вкладке Actions либо отправьте
   следующий коммит в `main`.

Workflow проверяет проект и публикует сборку. Путь определяется автоматически
через GitHub Pages, поэтому имя репозитория не нужно прописывать в конфигурации.
Ссылки с параметрами поиска работают без серверного роутинга.

Для собственного домена сначала настройте его в Settings → Pages, затем запустите
публикацию повторно. Для сборки вручную с нужным путём используйте:

```sh
VITE_BASE_PATH=/ural-test/ npm run build
```

[Инструкция Vite по публикации на GitHub Pages](https://vite.dev/guide/static-deploy.html#github-pages).
