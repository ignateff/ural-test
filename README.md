# Подбор автозапчастей

React SPA для подбора искомой детали, аналогов и складских предложений Favorit Parts.
JavaScript, Redux Toolkit, Bootstrap и Vite; запросы идут из браузера прямо к HTTPS API
поставщика с поддержкой CORS.

## Запуск

Требуется Node.js 22.20+ или 24.12+.

```sh
npm ci
npm run dev
```

Vite выводит адрес в терминале. Примеры артикулов: `01089` (ASAM или FEBI),
`7160500039S`. Доступность и лимиты примерного ключа зависят от поставщика.

При необходимости скопируйте `.env.example` в `.env` и задайте `VITE_FAVORIT_API_KEY`.
В SPA ключ попадает в клиентскую сборку и доступен посетителю; переменная окружения
не делает его секретным. По умолчанию используется публичный ключ из документации.

## Проверки

```sh
npm run format         # записать форматирование Prettier
npm run format:check   # проверить форматирование
npm test              # интеграционные проверки и модель
npm run test:a11y      # доступность интерфейса, включая axe
npm run build         # статическая production-сборка в dist/
npm run check         # форматирование, все Vitest-тесты и сборка
```

Браузерные проверки требуют Chromium, устанавливаемого Playwright:

```sh
npx playwright install chromium
npm run test:browser
```

Playwright сам запускает отдельный Vite на `127.0.0.1:4173`; этот порт должен быть
свободен. Ответы Favorit Parts подменяются подготовленными данными, внешний ключ
и работающая страница приложения не нужны. Проверяются дропдауны, клик по всей
строке, Space, Escape, возврат фокуса, URL, локальная фильтрация, низкие экраны
и компактная шапка результатов.

GitHub Actions на push и pull request запускает `npm ci`, `npm run check` и
браузерные тесты. При ошибке сохраняются HTML-отчёт, trace и screenshot.
Результаты находятся в `test-results/`, HTML-отчёт CI — в `playwright-report/`.

`npm run preview` открывает локальный просмотр сборки. Содержимое `dist/` можно
разместить на статическом HTTPS-хостинге.

## Структура

```text
src/
  main.jsx                  # точка входа и порядок подключения стилей
  app/                      # страница, шапка сайта, создание Redux store, общие стили
  parts-search/
    api/                    # HTTP Favorit Parts и преобразование ответа
    model/                  # Redux slice, фильтрация, сортировка, состояние URL
    ui/
      search/               # ввод артикула и выбор производителя искомой детали
      offers/               # результаты, таблица, сортировка, виртуализация
      filters/              # модальное окно, группы фильтров, дропдауны и теги
      feedback/             # загрузка, ошибка и доступные сообщения статуса
    styles.css              # вход для стилей подбора

test/
  app/ search/ offers/ url/ # проверки по областям приложения
  support/                 # рендер настоящих React/Redux, fetch-заглушки, аудит axe
  setup.js                 # настройка JSDOM

e2e/
  offers/                   # браузерные сценарии
  support/                  # HTTP-фикстура браузерных проверок
```

Цвета основаны на [странице FAVORIT](https://favorit-parts.ru/reg/) и собраны в

[Границы модулей и правила навигации](docs/architecture.md).

## Поведение

После паузы ввода 500 мс загружаются производители. Выбор производителя загружает
искомую деталь и аналоги. Одна строка результата — одно складское предложение:
цена берётся из `warehouses[].price`, остаток — из `warehouses[].stock`. Деталь
без складских предложений остаётся в списке с прочерком вместо цены. Вложенные
аналоги учитываются; пустые структуры из ответа исключаются.

Есть загрузка, повтор запроса, ошибки, пустые результаты, таймаут 20 секунд,
отмена запросов и защита от устаревших ответов. Контракт поставщика:
[документация Favorit Parts](https://lk.favorit-parts.ru/static/wsprice.pdf).

Над результатами — заголовок с кнопкой фильтров, ниже выбранная деталь со
счётчиком и сортировкой. Теги выбранных условий позволяют удалить отдельный
фильтр или сбросить все, сохранив сортировку. Дропдауны склада и производителя
поддерживают поиск и множественный выбор. Выбор применяется сразу, локально.
Модальная панель справа имеет ширину 380px; до 575px занимает весь экран.
Escape сначала закрывает дропдаун, затем панель; Tab остаётся внутри панели,
после закрытия фокус возвращается к кнопке. Закрытие и возврат к предложениям
доступны независимо от прокрутки содержимого.

Фильтрация предшествует сортировке, затем виртуализации. При более 100 строках
в DOM находится измеряемое окно с запасом; полная высота таблицы сохраняется.
Прокрутка документа достигает всех предложений. Поиск браузера и печать видят
только отрисованное окно. Заголовки закрепляются под фактической высотой панели
поиска; до 575px та же таблица выглядит как карточки.

## URL

Ссылка восстанавливает подбор, фильтры и сортировку. `history.replaceState`
не добавляет записи истории; посторонние параметры и хэш сохраняются.
Производитель искомой детали из ссылки сохраняется, даже если отсутствует
в текущем списке поставщика. Некорректные значения нормализуются или удаляются.

| Параметр               | Значения                                                        |
| ---------------------- | --------------------------------------------------------------- |
| `number`               | Артикул искомой детали                                          |
| `brand`                | Производитель искомой детали                                    |
| `sort`, `order`        | `price` / `stock` / `brand` / `warehouse` и `asc` / `desc`      |
| `stock`                | `in` / `out`; отсутствие — все строки                           |
| `wh`                   | Название склада; повторяется для нескольких складов             |
| `brands`               | Производитель строки; повторяется для нескольких производителей |
| `kind`                 | `original` / `analogue`; отсутствие — все строки                |
| `priceFrom`, `priceTo` | Конечные десятичные числа с точкой; пустая граница отсутствует  |

## Доступность

Интерфейс использует нативные элементы управления, подписанные поля и таблицу,
ссылку перехода к содержимому и заметный клавиатурный фокус. Статусы объявляются
короткими сообщениями; вся таблица не включена в live region. Учитывается
предпочтение уменьшенного движения.

Vitest использует настоящие React/Redux и подменяет только `fetch`. JSDOM не
рассчитывает геометрию и контраст: `color-contrast` в axe отключён явно.
Нативные dialog, фокус и размещение проверяются в Chromium; автоматический
аудит не заменяет прослушивание скринридером.
